# RAG Application

Приложение для Retrieval Augmented Generation (RAG), созданное на Go, с соблюдением принципов чистой архитектуры.

## Возможности

- **Чистая архитектура** - модульная структура с разделением ответственности
- **Интеграция с Ollama** - для embeddings и генерации текста
- **Векторная база данных Qdrant** - для семантического поиска и хранения
- **Умный механизм синхронизации** - инкрементальные обновления с сохранением состояния
- **Логика разбиения текста на чанки** - 1500 символов с перекрытием 200 символов
- **Отладочный интерфейс** - HTML-интерфейс с Bootstrap для поиска и отображения результатов

## Требования

- Go 1.22+
- Docker (для сервиса Qdrant)
- Ollama (запущенная локально в сети хоста)

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   go mod tidy
   ```

3. Запустите необходимые сервисы:
   ```bash
   docker-compose up
   ```

4. Подтяните необходимые модели Ollama:
   ```bash
   ollama pull nomic-embed-text
   ollama pull qwen2.5:7b
   ```

5. Запустите приложение:
   ```bash
   go run main.go
   ```

## Конфигурация

Конфигурация загружается из файла `.env`. Значения по умолчанию:
```
OLLAMA_HOST=http://localhost:11434
MODEL_EMBEDDING=nomic-embed-text
MODEL_GENERATION=qwen2.5:7b
QDRANT_HOST=localhost:6334
SYNC_INTERVAL=10m
```

## Как это работает

1. **Начальная синхронизация** - При запуске приложение обрабатывает контент и сохраняет embeddings в Qdrant
2. **Инкрементальная синхронизация** - Регулярные обновления контента по заданному интервалу  
3. **Процесс поиска** - 
   - Запрос преобразуется в embedding с помощью Ollama
   - Семантический поиск в Qdrant для нахождения релевантных фрагментов
   - Формирование контекста из результатов поиска
   - Генерация ответа с помощью LLM с использованием контекста
